Git Basics Activity

1. `git status` – Checks the current state of the repository.
2. `git add git-activity.txt` – Stages the activity file.
3. `git commit -m "Add initial Git activity file"` – Records staged changes.
4. `git push` – Uploads local commits to GitHub.
5. `git pull` – Downloads and integrates remote changes.
6. VS Code Source Control – Provides a graphical interface for staging, committing, and synchronizing files.
